# ALPHA-DELIVERY-R1

First tagged delivery round in `AlphaProject`. The aim was not to prove general productivity gain,
but to establish a repeatable baseline for:

- gate friction,
- retrieval activation and application,
- tool usage and session span,
- token/cost under a known model,
- mechanical conformance to scoped task acceptance.

See [`manifest.json`](manifest.json) for the workspace, payload, model, and confounder tags.

## Contents

- `metrics/` — backfilled session, roundtrip, and gate-block CSVs for PBI 0–4
- `runs/` — declarations for reproducible extraction; original runs were CLI invocations
- `scores/` — rubric score artifacts where a rubric was applied
- `results/links.md` — pointers to run records and interpretation

This round is complete. Interpretation and a consolidated comparison table are deliberately
deferred until after the round review. Do not treat the raw numbers as causal evidence.
